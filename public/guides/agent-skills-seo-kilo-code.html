Quick answer

Run npx skills add, scroll the dozens of skills and press space to select, choose Claude Code and Kilo Code as targets, install globally and pick symlink. Then run them on a real site: the image skill flagged a large avatar and images without width and height, the Core Web Vitals skill worked on LCP, CLS and INP, and an IndexNow skill generated a script that submits every URL to Bing, run with npx tsx. A PageSpeed retest showed about the same speed and Core Web Vitals still failing, with desktop at 97.

This is an April 2026 walkthrough on my SaaS site, run mostly in Kilo Code because it is free to use when my Claude Code credits run out. The skills are open source, and you should read what a skill does before it edits your project. For the Claude Code version of an SEO skill, see the Claude SEO skill guide.

Who this is for and what you need

This guide is for a site owner who wants a set of free, open-source SEO skills installed once and usable from several coding agents, then run against a real site. My test site was TubeAnalytics, a SaaS I own, in April 2026.

  • Good fit: you hit weekly limits in Claude Code and want the same skills in a free agent such as Kilo Code or OpenCode.
  • Not covered here: one all-in-one audit skill. The Claude SEO skill guide covers that approach.
  • What you need: Node.js for npx, at least one coding agent, your site's code in a repository and a way to retest, such as PageSpeed Insights.

1. Install skills

Run npx skills add and choose from the list; space selects and enter confirms. I had already installed ten or twelve. You then pick which tools to install them in, here Claude Code and Kilo Code, whether to install in the project or globally, and whether to symlink or copy to all agents. I recommend symlink so one copy updates everywhere.

2. Image and Core Web Vitals skills

The image optimization skill flagged a very large avatar image, images missing width and height attributes and no images in the sitemap. The Core Web Vitals skill then worked on LCP, CLS and INP problems. In Kilo Code you can watch each step it takes.

3. IndexNow and schema

The IndexNow skill generates a script that submits all your pages to Bing so it crawls them quickly. I ran it with npx tsx. Another skill adds blog schema for rich results and checks that pages validate.

4. Search Console and the retest

The Search Console skill has no direct access to your account, so I asked it for a monitoring script instead. After the fixes I ran PageSpeed Insights again. The overall speed was about the same, the Core Web Vitals assessment still failed and desktop scored 97 out of 100. I do not know why the skills did not move the score, so check results rather than assuming.

Running several skills side by side

Because the skills were installed globally with a symlink, I could run them in Kilo Code and OpenCode at the same time, one skill per window. That is the main advantage of installing them this way.

Image skill findings

Its audit said the site had a solid foundation with areas to improve, then listed a large avatar to convert to a smaller format, blog images without width and height, no images in the sitemap and a logo still served as a fallback. I answered fix everything and watched it convert the avatar and add an image sitemap extension.

The parasite SEO skill

Given my domain, it suggested backlinks from Reddit, Medium, LinkedIn Pulse, Quora and Stack Overflow, plus content clusters. I already had clusters, written with a separate blog skill I built for Claude Code.

Search Console without access

The Search Console skill asked for my domain, then said it had no direct access to my account and asked how to proceed. Its checklist covered adding the site, settings and the sitemap, which I had done. The useful output was a simple monitoring script it offered to write.

IndexNow covers Bing, not Google

The IndexNow script submitted every URL to Bing when I ran npx tsx on it from a new terminal tab. I had not found an equivalent way to push pages to Google.

To check whether AI crawlers visit after changes like these, see Trakkr and Codex. For a broader list of skills worth installing, see npx skills: ten coding agent skills. New to Kilo Code? Start with the Kilo Code tutorial.

FAQ

Are the skills free?

Yes, they are free and open source. The tool you run them in may have its own costs.

Why Kilo Code?

It is free to use, so I switch to it when I run out of Claude Code credits.

Did page speed improve?

Not noticeably. Desktop was 97 and Core Web Vitals still failed.

Can one install of the skills work in several agents?

Yes. I installed them globally with a symlink for Claude Code and Kilo Code, and also ran them in OpenCode at the same time.

Does the IndexNow skill submit pages to Google?

No. Its script submits URLs to Bing. I had not found a way to do the same for Google.
