Who this is for and what you need

This guide is for someone curious whether Manus can handle everyday Google tasks on its free model before paying for a plan. It was my first time using Manus, in January 2026.

  • Good fit: you want to see what the free Lite model does with real Calendar and Gmail connectors, including where it fell short.
  • Not covered here: the paid Pro or Max models. I did not sign up for them.
  • What you need: a Manus account, a Google account with Calendar and Gmail, and an OpenAI or Gemini API key if you want it to write replies.

1. Pick a model

The options were Manus 1.6 Lite, 1.6 Pro and 1.6 Max. Pro and Max needed a free-trial or paid plan, so I used Lite.

2. Connect Google Calendar

Connect Google Calendar from the tools list, then run the suggested prompt to test the connector. Manus found the Google Calendar MCP tools, created an event I could see on my calendar and updated it. When I asked it to delete the event, the event stayed on my calendar. You can open the task to see the Ubuntu Linux machine and commands it ran.

3. Connect Gmail

After connecting Gmail, Manus listed my latest emails. I then asked for a lead-flow SaaS build, which the Lite model could not handle. That is where the Pro tier is meant to help.

4. Build the autoresponder

I asked Manus to auto-respond to all emails. It wrote a Python responder using OpenAI and set an hourly scheduled task that reads unread messages and drafts replies. I added an OpenAI key and a Gemini key from Google AI Studio through the custom API connectors, then asked it to switch the responder from ChatGPT to Gemini. It rewrote the script to use the Google Gen AI library. I prefer Gemini because I have API credits there.

I did not show it sending or replying to any real email, so treat it as drafts until you have tested.

What Manus said and did at each step

Testing the connectors

Each connector comes with a suggested prompt, such as Help me test the Google Calendar connector and show me how to use its features. Manus answered that it would test the connector with real data and summarise its capabilities. For Gmail it listed tools like searching and listing messages with an optional query and label filter.

The Lead Flow build

I asked it to build a sales lead tracker for a SaaS product named Lead Flow. Manus started on a modern SaaS style site, then said the task needed more firepower than Manus 1.6 Lite. I understood Max to be about $167 a month at the time, and a free trial was offered. I did not take it.

How the autoresponder was set up

When I asked it to respond to emails with an AI agent, Manus asked whether to reply to all incoming emails or only some. I said all. It explored the Gmail MCP tools, wrote a Python responder and confirmed a scheduled task that runs every hour. Adding the OpenAI key through manage connectors was confusing because I could not see where the key was saved at first. I switched to Gemini because I had API credits there and kept running out on OpenAI. Manus also showed Nano Banana Pro as a free option, which I skipped because I use another platform for images.
