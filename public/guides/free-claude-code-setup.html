Quick answer

On 5 May 2026 I cancelled Claude Pro, cloned the Free Claude Code GitHub project (about 21,000 to 22,000 stars that day), copied .env.example to .env, added an NVIDIA NIM key from build.nvidia.com and an OpenRouter key, then started the local proxy on port 8082. A test reply used NVIDIA NIM GLM 4.7 and was slower than Pro. I later preferred OpenRouter StepFun 3.5 Flash, which I said was 10 cents per million tokens. A Next.js AI-search app started in a new folder and was not demoed finished. This is the community proxy, not the official Claude Code install.

Official Claude Code install is in Claude Code for beginners. Why I later moved off this proxy is in Free Claude Code vs OpenCode vs Codex. The clone and proxy start commands were copied from GitHub and not read aloud, so they are not reconstructed here. Description-footer product links are not pasted here.

1. Leave Claude Pro if you are switching

I opened billing, chose the red cancel-plan control, picked taking a break, and submitted. I said Claude Pro was about $20 a month and Max about $100 a month, and that Max was not necessary for this setup. You can keep a paid plan. I cancelled because I wanted a $0 build path.

2. Clone Free Claude Code and fill .env

The project from the video description is github.com/Alishahryar1/free-claude-code. I copied the git clone command from that page and changed into the folder. I copied .env.example to .env. Keys listed in that file included NVIDIA NIM, OpenRouter, DeepSeek, Kimi, and LM Studio. I filled NVIDIA NIM and OpenRouter only.

3. Add NVIDIA NIM and OpenRouter keys

On build.nvidia.com I created an account, opened a popular Llama 4 playground until it replied that it was working, then generated an API key named "free Claude Code" with a 12-month expiration and pasted it into .env. On OpenRouter I generated a key with the same name, pasted it, and saved. Optional providers named on camera were DeepSeek, Kimi 2.5, LM Studio, and Ollama.

4. Start the proxy and test Claude

GitHub said to start the proxy on port 8082. I did not read that start command aloud. A second command pointed Anthropic's base URL at the proxy, then launched Claude. Stats showed I was no longer using the Anthropic API. I typed:

test

It replied that the test was received and the system was active. The model was NVIDIA NIM GLM 4.7, which I said was slower than Pro.

5. Start a Next.js app, then stop

I asked it to create a simple app, then a Python stock-data extractor, then abandoned that for a new folder called AI search tool. Claude Desktop wrote a prompt to build an AI search visibility app from a link I did not read aloud. I approved CLAUDE.md. The agent wrote package.json, tsconfig, Tailwind, layout.tsx, and middleware.ts as a Next.js MVP. I said tokens were essentially free. OpenRouter showed about a dollar, later $1.68 unused. I recommended StepFun 3.5 Flash on OpenRouter at 10 cents per million tokens because the default GLM 2.4 was slow. The finished app was not shown.

Done when

  • Cloned Free Claude Code and copied .env.example to .env

  • Started the local proxy and got a test reply from Claude

  • A finished Next.js app. The MVP files were written. I did not demo a running product.
  • Whether GLM 4.7 or StepFun still match those names and prices today.

FAQ

Is this official Claude Code?

No. It is the Free Claude Code GitHub proxy. Official install is a separate beginner guide.

Which keys did you add?

NVIDIA NIM from build.nvidia.com and an OpenRouter key. Both were named free Claude Code.

What port did the proxy use?

Port 8082, from the GitHub run instructions.

Did the Next.js app ship?

No. The agent wrote starter files. I did not show a finished app on 5 May 2026.
