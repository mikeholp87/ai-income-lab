CleanYourTV with Claude Code: TCL Setup and Risks

Quick answer: Check that your TV runs Android TV or Google TV, turn on USB debugging, paste the CleanYourTV prompt into Claude Code and let it back up the TV before it changes anything. On my TCL it disabled the apps I don't use and installed a much cleaner, faster home screen, but several remote buttons stopped working. Keep the restore command handy and test every button before you call it done.

CleanYourTV is a free GitHub project that disables ad services, preloaded apps and content rows on Android TV and Google TV, then installs a small launcher as the new home screen. That is a real device modification. My TV is a TCL I bought in Thailand for around $300, and Claude Code identified it as a TCL Smart TV Pro running Google TV on Android 12.

The official CleanYourTV site says the prompt will not work on Samsung Tizen, LG webOS or Fire TV, and points owners of non-Android sets to a separate page. Look up your exact model on the site first.

Prepare before connecting

You need the TV, its remote and a computer on the same Wi-Fi network running a coding assistant with shell access. I used Claude Code. Before I started, the TV's memory usage sat at about 65%, and the home screen was full of apps and rows I never touch.

Note what you rely on before anything changes: the streaming apps you use, how inputs behave and which remote buttons you press. The project's prompt backs up the package list and settings and writes a restore script. That makes recovery much easier, but it isn't a promise that every firmware problem can be reversed.

Only do this on your own TV from a computer you trust. Debugging access lets that computer control the TV, so switch it off when you're finished.

1. Turn on developer options and USB debugging

On my TCL I went to Settings, System, About, then pressed OK on Android TV OS build seven times. That unlocked Developer options, where I turned on USB debugging and confirmed the prompt. The CleanYourTV prompt describes the same steps under Device Preferences, and Android's developer documentation notes that the build number and Developer options can sit in different places on different devices.

Claude Code then ran ADB, found the only device on my network with port 5555 open and cloned the project. The TV kept asking me to allow USB debugging, so I ticked “Always allow from this computer” to stop the repeated prompts.

Claude Code's auto mode got in the way here, so I turned it off, typed “continue” and approved each command as it asked. For changes to a device, that is what you want anyway.

2. Paste the project prompt and let it back up first

I copied the prompt straight from the site into Claude Code. It took a full backup of the TV before changing anything, then asked which streaming apps I use. Anything left unticked gets disabled. It also asked about casting and voice features and how many apps I wanted in the dock.

Answer carefully. An unused streaming app is very different from the services that handle settings, inputs, remote pairing or boot. The project disables packages in small batches with its own disable.sh script rather than uninstalling them. Don't swap that for a generic “remove all bloat” request.

3. Keep the apps and controls you actually use

I kept Netflix, YouTube, Spotify, Max and Haystack News, and only Google Assistant voice. It disabled Prime Video, Chromecast, AirPlay and Miracast, which I never use here, and it looked like it was also switching off some telemetry. I picked the recommended four-app dock. It took a before screenshot, then rebooted the TV to see whether the firmware turned anything back on.

After the reboot the menus and settings opened noticeably faster. That is my impression from using it, not a measured benchmark. I also realized it had disabled YouTube Music, which I do use, so I turned it back on.

The whole session was light on usage. I was running Opus 5.5, and the current session showed only about 5% used.

4. Launcher build and the Wi-Fi step

I didn't have the Android SDK installed, but I had Docker, and the repo includes a Docker build. Claude Code used that instead. The first run built an image of roughly 1.5 GB, then reported the launcher APK was built.

Before installing it, Claude Code stopped and asked me to go to the TV. My Wi-Fi network had been saved by Google's setup wizard, and disabling the wizard would delete that network and take the TV offline. So I went to Settings, Network and internet, forgot the network, joined it again with the password and replied “done.” The CleanYourTV README describes this exact Google TV case. Don't forget your network on a TV that doesn't need it.

5. Test the physical remote before calling it finished

The new home screen looked far cleaner, with only my apps in a dock of YouTube, Netflix, Max and Spotify. Netflix, HBO and YouTube all opened faster for me. I applied the Scenes theme, which pushed 14 background images, and queued the clock screensaver, hourly wallpaper rotation, the time-of-day backdrop and the quick settings panel.

Then Claude Code asked me to press each remote button and tick the ones that worked. Power worked. Settings, Netflix and YouTube did not, and at that point I didn't think any of the shortcut buttons were working. Settings was still broken at the end of the video. Earlier it had warned that on this TV the Netflix and YouTube buttons stop working once Google TV's home is disabled, and recommended the launcher's key helper. I think some of the glitches I hit were because it was still running commands and rebooting the TV in the background.

Test Home, Settings, inputs, app shortcuts, power, volume and long presses on the real remote. A screenshot can't tell you whether a physical key works.

Check the connection and keep the restore command

Before you paste the prompt, you can confirm your computer can reach the TV using the commands in Android's ADB documentation. Replace the address with your TV's IP:

adb connect device_ip_address:5555
adb devices

A working connection lists the address followed by device. If it drops, the same page says to check you're still on the same Wi-Fi, run the connect step again and, if that fails, reset the ADB server with adb kill-server.

Then keep the undo. The CleanYourTV README says to keep the list you applied and gives a one-line restore. On Google TV, which is what my TCL runs, it adds the stock launcher package:

TV_HOST=192.168.1.50 tools/restore.sh examples/<your tv>/debloat.txt com.google.android.apps.tv.launcherx

Use your TV's IP and the list written for your model. On a plain Android TV, drop the last argument.

Limitations and recovery

Restore re-enables what was disabled, but the README says the new launcher stays installed until you remove it in Settings, Apps. If the TV can't be reached from a computer, the same Settings page can re-enable packages. A firmware update can bring disabled apps back, and the project has a check for that.

The README also warns that on some TCL Smart TV Pro sets, getting back to Google TV's own launcher can need ADB. Keep your backup and stop if a step falls outside what the project documents for your model. When you're done, switch USB debugging off again in Developer options.

FAQ

Did it fix every remote button?

No. After the new launcher went in, my Settings, Netflix and YouTube buttons didn't work when I tested them, and Settings was still broken at the end of the video. Power worked. Test every button on your own remote before you call it finished.

Will this remove every advertisement?

No. It disables ad services, content rows and preloaded apps and replaces the home screen. The project's FAQ says Android's Private DNS with an ad-blocking resolver can partly block ads inside apps, but that doesn't remove YouTube ads.

Will it work on my TV?

Only on Android TV and Google TV sets. The project says the prompt won't work on Samsung Tizen, LG webOS or Fire TV and sends those owners to a separate non-Android page. Check your exact model on cleanyour.tv first. Mine was a TCL Smart TV Pro running Google TV on Android 12.

How do I undo it?

Run the project's restore script with the list you applied, as shown in the restore section above. It disables packages rather than uninstalling them and records the TV's state first, so restore can re-enable them. The new launcher stays installed until you remove it in Settings, Apps.
