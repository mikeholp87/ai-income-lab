Quick answer

Cortex is a personal Claude Code project that stores business notes in markdown, adds a Radar view and a theme graph, and pulls tools such as VidIQ over MCP. The 17 July 2026 recording is a tour. It is not an installable product, and the LeadScope prompt text was not spoken.

If you need Claude Code itself first, use Claude Code for beginners. MCP as a protocol is What is MCP?. Switching harnesses when a limit hits is the same idea as Codex vs Claude Code.

What this recording shows

Cortex is described as a business second brain with a library of app projects and both YouTube channels, trained on a knowledge base with a RAG system. Work happens in Claude Code and Codex. The recording is a public build tour from 17 July 2026. No public product page or installer was shown, so this page does not treat Cortex as something you can download.

1. Project files and markdown

A Python script in Claude Code pulled transcripts for the AI Automation Station channel. The second channel still needed the same pass. That channel had about 1,200 videos, so it was left for later.

Twenty-six project files were already in the repo. Each was a markdown file made in Claude Code, with tech stack, current state, features, and some file structure. Capture accepted pasted thoughts, links, and notes into an inbox. Spaces listed current projects, including the YouTube channel and a lead-generation tool.

Before the VidIQ check, he asked for a commit and push to GitHub. The caption track heard get commit and push, so that line is not copied as a command.

2. Radar and the theme graph

Radar was being built to say what to build next and what to shoot next for YouTube. The recording hoped it could give foresight without an outside consultant. No later result from Radar was shown.

A theme-graph tab appeared after a refresh: connected nodes, animated. Capture sat beside it. Those views are what was on camera, not a published Cortex UI you can sign up for.

3. VidIQ MCP and the Codex handoff

VidIQ was already connected. This was spoken:

/mcp

Spoken at 03:26. The list included VidIQ with a balance of 1,390 credits and eight content recommendations, described as a free balance check.

The next ask was Radar recommendations from that VidIQ data. LeadScope was a separate wish: daily contacted-lead counts and open rates from the CRM, pulled into Cortex. Claude Code was told to create a detailed prompt that would pull LeadScope data and build an analytics dashboard. That prompt was pasted into Codex. The prompt text was not spoken, so it is not copied here.

The move to Codex was a rate-limit handoff. Claude Code was out of credits, with a reset about 45 minutes away. Codex still had 91% of the week left. A Tube Analytics integration was also in progress, using that product’s own MCP. Tube Analytics was described as live, about 1,400 hours in, with a 7-day free trial and prices from $19 to $149 per month on 17 July 2026. Check live pricing before you spend.

Claude Haiku was used for summaries. The summary queue was clear: 218 summaries created, no pending jobs, and the worker found nothing new.

Other Claude Code builds from this batch are Claude Fable 5 Game Prompts and Claude Code Video Editor Skill: Build and Run. Another MCP-to-Codex loop is CrowdReply MCP with Codex.

FAQ

Can I install Cortex as a product?

No public install was shown. Cortex is a personal Claude Code project from the 17 July 2026 recording: markdown files, a Radar view, a theme graph, and connected tools.

Why did the build move to Codex?

Claude Code was out of credits, with a reset about 45 minutes away. The LeadScope prompt was pasted into Codex, which still had 91% of the week left.

Was the VidIQ MCP added during this recording?

It was already connected. Running /mcp listed VidIQ with a balance of 1,390 credits and eight content recommendations.

Did Radar prove what to build next?

No. Radar was being built to suggest what to build and what to film. The recording did not show a measured outcome from those suggestions.
