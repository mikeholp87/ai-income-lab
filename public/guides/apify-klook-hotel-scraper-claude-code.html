This is a February 2026 build for a luxury hotel directory I made for Koh Samui, Thailand. Apify sponsored the video, and the link below is an affiliate link. Scraping a site can break its terms, so check Klook’s terms and robots rules and only collect what you are allowed to use. For a first run with these skills, see the Apify agent skills guide.

1. Why scrape and what Apify offers

My hotel directory needed accurate data, and many prices were wrong. Booking.com makes prices hard to scrape because you must pick dates. The Apify Store lists about 19,000 actors, including scrapers for Google Maps, TikTok, YouTube transcripts, Facebook posts and TripAdvisor. Apify is free to start.

2. Install the skills

Search for Apify agent skills to find the GitHub page and run the one-line command in the terminal: npx skills add apify/agent-skills. The installer lists the skills available, including one for scraping many sites. I worked in Visual Studio Code with Claude Code.

3. Run the scraper and fix it

I asked Claude Code to scrape Klook for luxury four and five star hotels in Koh Samui. It started the Apify ultimate scraper skill and looked for a suitable actor in the store. The first search returned Walt Disney World results, so I passed the direct Klook accommodation URL. It cost only a few cents of Apify credit. Output included hotel names such as a Centara resort and Vanabel, plus reviews, scores and map locations.

Prices were empty because Klook returns them only with check-in dates. Claude Code offered to add dates to the URL and rescrape, and I said yes. I expected about 450 hotels in the full scrape and did not wait for it on camera.

4. A custom Playwright scraper

When an actor did not fit, Claude Code wrote its own Playwright script that captured Klook’s hotel API response and scrolled to load more results. It saved about 49 hotels to JSON. I used the earlier JSON scrape of 140 or more hotels to build the site pages. For income from such a site, I mentioned affiliate links and travel payouts; I did not show results.

What this recording did not cover

  • The finished rescrape with prices. The recording ended while prices were still loading.
  • Whether scraping Klook is allowed under its terms. Check them yourself.
  • Apify cost for a full 450-hotel scrape beyond the few cents of the first run.
