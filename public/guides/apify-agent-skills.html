Quick answer

Install the Apify agent skills with npx skills add apify/agent-skills, add your Apify API token to a .env file as APIFY_TOKEN, and run the lead generation skill from OpenCode in Cursor. In the 5 February 2026 recording, a Google Maps scrape of AI startups in San Francisco wrote 74 leads to a CSV with names and websites but no emails, so a second contact info scrape pulled emails from those sites into another CSV. The same install command can be used in Claude Code, though that path was described, not shown end to end.

This walkthrough is from a video sponsored by Apify. The signup link is an affiliate link, so I may earn a commission or credit. Current plan prices are on the Apify card on the tools page.

1. What you build

The recording is a short lead-scraping example, not a full outreach system. You install Apify agent skills, connect an API token, and ask an agent to scrape a list of AI startups in San Francisco. That first run uses a Google Maps scraper and writes a CSV of companies and websites. A second skill then visits those sites and writes email addresses to another CSV.

Mike says he has used Apify for a couple of years, and that it has integrations for Google Maps, TikTok, YouTube, Facebook and Instagram, among others. He also says there are thousands of apps you can scrape. The demo itself uses the lead generation skill and then a contact info scraper.

2. Install the agent skills

Open the Apify agent skills GitHub readme and copy the install line that uses the Node.js package manager. In the recording that command is:

npx skills add apify/agent-skills

Run it in a terminal if you want the skills installed globally on your system, which is what Mike did. The installer asked to proceed, then cloned https://github.com/apify/agent-skills.git and reported 12 skills. Use the spacebar to toggle the ones you want. The recording selected all 12, including lead generation, content analytics, competitor analysis and audience analytics.

After the skills were selected, the installer asked for a target editor. Mike chose Cursor, installed into his home directory, and accepted a symlink. The run finished with a notice that Replit does not support global skill installation. It then offered a one-time find-skills skill, which helps an agent discover and suggest skills. He accepted that too. The find-skills source shown on screen was https://github.com/vercel-labs/skills.git.

The same readme also listed Claude Code plugin commands, which the recording did not run:

/plugin marketplace add https://github.com/apify/agent-skills
/plugin install apify-ultimate-scraper@apify-agent-skills

You can also clone the repository instead of installing globally. Mike chose the global install so the skills would be available in Cursor.

3. Open a Cursor project

Create a new project folder in Cursor. In the recording the folder was named Cursor under Documents, at /home/mikeh/Cursor/. Open a terminal in that project and start OpenCode, then ask it to list the skills it can use:

list all of the agent skills you have access to

OpenCode listed the newly installed Apify skills, plus a Remotion skill that was already present on that machine. Then run the lead generation skill:

run apify-lead-generation skill

4. Add your Apify token

The first attempt failed the way the skill's own docs predicted. OpenCode asked for permission to read a .env file, then reported that no token was found.

Create a .env file in the project and set your Apify API token. The variable name shown on screen was APIFY_TOKEN. Do not commit that file, and do not paste a live token into a video or a page. Use your own token from the Apify console:

APIFY_TOKEN = "your_apify_token"

After the token was in place, the same prompt was sent again:

run apify-lead-generation skill

OpenCode read the skill file and started a Google Places crawl, which Mike took as a sign that the token was working.

5. Scrape AI startups to a CSV

That first successful run had no search terms yet, so the skill scraped coffee shops in Seattle, Washington, including opening hours and other Google Maps fields. Mike did not want that list. He stopped and gave a specific prompt:

run apify-lead-generation skill and find ai startups in san francisco and add them into a csv database

That run also used Google Places. You can watch the job in the Apify console under Runs. The recording showed a Google Maps scraper collecting AI startups in San Francisco, with websites attached, and no email addresses in those results.

When the run finished, OpenCode had written a CSV in the project folder. The file shown on screen was 2026-02-05_ai-startups-san-francisco.csv, with 74 leads and a size of 86,348 bytes. Columns included title, category, address, phone, website, rating and a Google Maps URL, among others.

6. Extract emails from the websites

Mike first looked in the Apify store for other ways to get emails. He mentioned an Apollo integration he thought had been removed, and a leads scraper then listed at $1 per 1,000 emails, including Apollo and LinkedIn profiles. That store price was what the recording showed in February 2026, so check the Actor page before you rely on it. He did not run that Actor in the demo. He asked the agent to use a skill instead:

run a apify skill to extract emails from the ai startups database

OpenCode chose the contact info scraper. In the recording it fed the website URLs from the first CSV into that scraper and looked for email addresses on each site. When it finished, it wrote another CSV that included the emails. The video does not check whether those addresses were accurate or deliverable.

7. Cursor, Claude Code and Linux

The live demo ran in OpenCode inside Cursor. Mike says you can set this up in Claude Code the same way, by entering the same install command after Claude Code is installed, including from Visual Studio Code. He did not walk through that path on camera.

He was using Linux, installed Cursor from the Linux download, and said he would rather use an editor like this than tools such as OpenClaw or Moltbot. On a Mac, he says you would install the Cursor executable instead.

8. Costs and limits

The recording starts with a free Apify account and says paid plans are also available. A firm current price was not established in the video. Plans on apify.com/pricing, checked on 12 November 2026, were:

  • Free: $0, with $5 of usage a month
  • Starter: $19 a month, or $17 a month billed yearly, with $19 of usage a month

In the recording Mike also pointed at a data-usage total of $1 spent out of $55 during that session. Treat that as one reading from that day, not a plan name or a current quota. Confirm today's usage and price in your Apify billing settings before you scale a scrape up.

FAQ

How do you install the Apify agent skills?

Run npx skills add apify/agent-skills in a terminal, select the skills you want with the spacebar, and choose the editor to install them for. The recording installed all 12 skills globally for Cursor, then accepted the optional find-skills skill.

Source: the 5 February 2026 walkthrough, at 1:21.

Do the Apify skills need an API token?

Yes. The lead generation skill reported that no token was found until a .env file was added with APIFY_TOKEN set to an Apify API token.

Source: the 5 February 2026 walkthrough, at 5:02.

Does the Google Maps scrape include email addresses?

No. The AI startups CSV in the recording had company names and websites but no emails, so a contact info scraper was run on those websites and wrote a second CSV.

Source: the 5 February 2026 walkthrough, at 7:33 and 9:29.

Can you run the same skills in Claude Code?

The recording says you can use the same install command in Claude Code, and the README on screen also listed Claude Code plugin commands. That path was described, not demonstrated end to end. The live demo ran in OpenCode inside Cursor.

Source: the 5 February 2026 walkthrough, at 11:45.

What does Apify cost?

The recording starts from a free account and mentions paid plans without a firm current price. Plans checked on apify.com on 12 November 2026 were: Free at $0 with $5 of usage a month, and Starter at $19 a month, or $17 a month billed yearly. Confirm the live price before you pay.

Source: Apify pricing, checked 12 November 2026, and the walkthrough at 0:29 and 11:36.
