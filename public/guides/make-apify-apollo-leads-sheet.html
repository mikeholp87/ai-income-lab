Quick answer

Copy the URL of an Apollo people search, then in Make.com create a Google Sheet, run the Apify Apollo actor with a JSON input holding that URL and a limit of 100 leads, get the dataset items, map first name, last name, email, phone, industry, country and city into an array and iterate it into sheet rows. It ran in about 30 seconds. A sheet-name clash had to be fixed first, and the phone column came back wrong, which mattered little because I wanted the emails.

This is a short June 2025 build. I used Apify because Apollo charges a credit for every lead added to its database and had tightened its limits. Scraping a service can break its terms of use, and cold email has legal rules, so check both before you use this. I offered a template on Gumroad, which you do not need to follow the steps. Who this is for and what you need

This guide is for someone who already knows how to filter people in Apollo and wants the results in a Google Sheet without spending Apollo credits or adding rows by hand. It is a short Make.com build from June 2025.

  • Good fit: you run the same kind of search often, for example heads of growth, and want a fresh sheet each time.
  • Not covered here: how to build the Apollo search, sequences and mailbox settings. Those are in the Apollo free plan tutorial.
  • What you need: Apollo, an Apify account (it gave $5 of free credit a month that reset on the first), Make.com and a Google account.

1. Pick the actor and the search

On Apify I chose an Apollo actor that can scrape large lists, and Apify gives free monthly credit of up to $5, so small runs may cost nothing. In Apollo, set up your people search with the filters you want and copy the page URL into the actor input.

2. Build the scenario

First a Google Sheets module creates a sheet called Apollo leads. Then the Apify run-actor module takes JSON with the search URL and a 100-lead limit. After it finishes, get dataset items using the ID from the previous step, put first name, last name, email, phone, industry, country and city into an array and iterate over it, adding a row per lead.

3. The two snags

The first run failed because a sheet with that name already existed, so I renamed it, and later left the name empty. After that it ran in about 30 seconds and added all 100 leads with emails. The phone number column came back wrong, so I ignored it.

4. What to do with the sheet

You can feed the emails into an email tool and use ChatGPT for the copy. Only email people you may lawfully contact, and include an unsubscribe route.

The scenario, module by module

  1. Google Sheets, create a sheet. I named it Apollo leads, then head of growth for the search I was running.
  2. Apify, run an actor. Choose the Apollo actor and pass JSON with the Apollo people search URL and a limit of 100 leads. The actor I picked said it could scrape up to 50,000 leads per run.
  3. Apify, get dataset items. Drag in the dataset ID from the run step.
  4. Array aggregator. Collect first name, last name, email, phone, industry, country and city.
  5. Iterator and add a row. Each lead becomes one row in the new sheet.

Fixing the sheet name error

The run stopped with a message that the sheet already existed. Renaming did not help on the second try, so I left the sheet name empty and the scenario ran. Plan a unique name per run if you want one tab per search.

After the run

All 100 rows arrived with emails in about 30 seconds and my Apify usage did not visibly increase. The phone field was wrong, so treat it as unreliable. I wrote the emails with ChatGPT and sent them from an email tool rather than Apollo. To write the outreach automatically, see the Make.com pitch builder. For a phone follow-up from the same sheet, the Vapi outbound caller dials rows from Google Sheets. Another Apify scraping example is the Klook hotel scraper with Claude Code.

FAQ

Why use Apify instead of Apollo credits?

Apollo charges one credit per lead added, and I had nearly used mine. Apify’s free monthly credit covered a small run.

How long did it take?

About 30 seconds for 100 leads.

Did every field work?

No. The phone column came back wrong.

What do I put in the Apify actor input?

JSON with the Apollo people search URL copied from your browser and a limit. I used 100 leads.

What if Make.com says the sheet already exists?

Give the sheet a new name or leave the sheet name empty. Leaving it empty is what let my run finish.
