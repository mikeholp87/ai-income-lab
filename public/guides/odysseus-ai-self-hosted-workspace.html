Quick answer

Clone the Odysseus repository from GitHub, create a Python virtual environment, install the requirements, start it on localhost and sign in with the username and password you create. That took about five minutes on Linux. Then add model keys in settings (an OpenRouter key found 341 models; I also added OpenCode Go, OpenCode Zen and OpenAI), set default chat and research models and try chat, agent mode, side-by-side comparison and a scheduled email digest. The shell tool and a local-model run were not set up, and the Gmail connection took several tries.

This is a June 2026 test of Odysseus, a free, open-source, self-hosted AI chat workspace that the video attributes to PewDiePie. I did not write it, and I have not audited its code, so read the repository and its permissions before you run it or give it your mailbox. The OpenCode Go link on this page is an affiliate link. For comparing the models you might connect, see choosing a model using your own task.

1. What it is

The project site describes chat, agents, tools and MCPs, a cookbook for installing local models, an email assistant, deep research, model comparison, memory and skills, and says it is private by default, with your data stored on your own machine. The repository had about 61,000 stars when I recorded it and was being maintained, with issues being fixed.

2. Install it

I cloned the repository, created a Python virtual environment, activated it and ran pip install on the requirements. There is a simple start command on macOS; on Linux I used the Python route. Then I started it on localhost and logged in with the username and password I created. The whole install took about five minutes.

3. Add models

In settings I added an OpenRouter key and tested it, which found 341 models, then added OpenCode Go, OpenCode Zen and OpenAI keys the same way. I set default models for chat and research and DuckDuckGo for search. A cookbook lists installs for local models and dependencies such as Playwright; I did not run a local model.

4. Chat, agents and comparison

The interface uses draggable windows that dock left or right, with themes. Chat mode works like a normal chatbot. Agent mode had no shell access until it was set up. You can compare two models side by side, which I used to see answers next to each other.

5. An email digest task

I asked the agent to create an evening email digest task for 7 pm, turned on two-factor sign-in and connected Gmail with an app password. It took several attempts. When it worked, asking it to check my inbox returned a summary of about 30 emails. Giving any tool mailbox access is a risk, so use a throwaway account to test.

FAQ

Is Odysseus free?

The project is free and open source. You pay for any model API keys you add.

Does it send data to OpenAI or Google?

It stores data locally, but any model you connect through an API receives your prompts.

Did it work on Linux?

Yes. Clone, virtual environment and requirements, then localhost, in about five minutes.
