Quick answer

On 27 April 2026 I cloned the GEO/AEO tracker GitHub repo (about 108 stars), ran npm install, added a Bright Data key, installed the Bright Data CLI, and opened a local dashboard on port 3000. An AEO audit showed 17 of 20 checks, average visibility around 95 percent, and AEO readiness 75 percent on TubeAnalytics. I added VidIQ, TubeBuddy, SocialBlade, and ViewStats as competitors, then turned on a 12-hour auto-run. Bright Data trial was $2.50 per 1,000 requests. I skipped a $500 a month upgrade. TubeAnalytics is my own product. This is not Otterly or VisiScan.

This free AEO tracker is a self-hosted GitHub project that checks AI visibility with Bright Data. TubeAnalytics is my own product. The tracker from the description is github.com/danishashko/geo-aeo-tracker. Paid-tool prices I quoted that day ($200 to $500 a month) were a reason I wanted a self-hosted option, not a live vendor list. For a hosted brand tracker I used later, see Otterly AI visibility tracking. VisiScan is my own scanner: VisiScan AI visibility audit.

1. Clone and install the AEO tracker

I had already cloned the repo. The git clone command was not read aloud. I ran:

npm install

I said it would integrate with Claude Code. A test command I spoke was:

npm run test scraper

That pull used Bright Data. Keep this app in its own folder so keys stay in this project's .env.

2. Add Bright Data and the CLI

I signed up for Bright Data with GitHub, skipped a paid plan, and used the free trial, which I said was $2.50 per 1,000 requests. A monthly upgrade starting at $500 a month was out of budget. .env wanted a Bright Data key plus ChatGPT, Perplexity, Copilot, Gemini, Google AI, and Grok. I copied scraper IDs from a URL and did not read those IDs aloud. OpenRouter was mentioned for later and not finished on camera. CLI commands I spoke:

npm install -g brightdata-cli

Then login, then add MCP for Cursor, Codex, and Claude Code. In Claude Code I used /mcp until Bright Data connected. I also put a skill in the .claude/skills folder.

3. Run the AEO audit

The dashboard ran on localhost 3000. AEO audit reported 17 out of 20 checks. I already had llms.txt, a full llms file, and robots. Fail or warn items were noscript fallback, JS weight, and reduce inline JS. Model toggles were GPT, Perplexity, Copilot, Gemini, Google AI, and Grok. A compare-all article warned that heavy pages may time out AI crawlers. Average visibility was about 95 percent. AEO readiness was 75 percent. Blog and guides sat around 80. Project settings included company name, SaaS as the industry, and a brand description.

4. Competitors and the 12-hour run

I added vidiq.com, TubeBuddy, SocialBlade, and ViewStats as competitors, then generated niche queries to optimize later in OpenCode. Auto-run every 12 hours was turned on. Funds dipped about 2 cents. I said the web scraper API was $1.50 per thousand records. Those spend figures are from 27 April 2026.
