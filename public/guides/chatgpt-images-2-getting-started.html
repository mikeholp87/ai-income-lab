Quick answer

On 23 April 2026 I opened chatgpt.com, started Images 2.0, ran OpenAI gallery-style prompts without reading those prompts aloud, then used the selection tool to change hair color and swap rabbits for elephants. I uploaded a selfie for a caricature, turned a house photo into a blueprint, made a sketch photorealistic, and asked for an identical book back cover with the same ISBN, which scanned to an Amazon listing. I repeated OpenAI benchmark talk of about 242 points over Nano Banana Pro 2 and about 300 over GPT Image 1.5. Those are the vendor figures from that day, not a test I ran. This is first use of 2.0, not the later Images 2.5 sketch workflow.

This is how I used ChatGPT Images 2.0 on 23 April 2026, from image mode to selection edits. The later sketch-to-scene workflow is ChatGPT Image Editing: Sketch-to-Scene and Local Edits. Thumbnail CTR work is ChatGPT Thumbnails: Audit CTR and Redesign. Gallery prompts I copied from the OpenAI site are not reconstructed here because I did not read them aloud.

1. Open ChatGPT Images 2.0 image mode

I went to chatgpt.com, dismissed a popup about a major image update, and clicked start creating to enter image mode. I walked the official gallery (text, languages, mockups, comics, a periodic table, blueprints, a pencil essay, anime, and film grain) without copying those prompts into this page.

2. Run a first generation

I ran the site's 35mm-film prompt without quoting it. The result was a similar coastline scene with a different character and grainy 35mm texture. A second gallery prompt I also did not quote came back futuristic and different from the gallery still. I then used the selection tool and said:

change the hair color to white.

That worked, a little funky. Then:

change the rabbits into elephants.

3. Upload, blueprint, sketch, ISBN

I uploaded a selfie and asked:

create a caricature of this person.

It recognized a Star Wars shirt, exaggerated ears and glasses, and put me on a tropical beach. I downloaded it and switched aspect ratio to landscape. A house photo with:

create a blueprint of this house.

matched pool, dining, great room, and hot tub. A Pinterest sketch with "turn this into an accurate photo of the person" came back photorealistic. For an Adam Grant Give and Take back cover I asked to create an identical image, making sure to keep the ISBN the same. Scanning that ISBN opened the Amazon listing.

Done when

  • Opened ChatGPT image creation mode
  • Generated one image and made one selection edit
  • Tried an upload-based edit and checked the whole frame

What I didn't cover

  • The OpenAI gallery prompts. I copied them from the site and did not read them aloud.
  • A controlled benchmark. The 242 and 300 point figures were OpenAI's, not a test I ran.
  • Images 2.5 Sketch. That is a later guide.

FAQ

Is this the Images 2.5 sketch guide?

No. This page is the 23 April 2026 Images 2.0 first-use test. Sketch-to-scene is a later guide.

Can I copy the 35mm prompt from this page?

No. I used the prompt on the OpenAI site and did not read it aloud.

Did the ISBN mockup scan?

Yes. I asked it to keep the ISBN the same, then scanned the result to an Amazon listing.

Did you measure those benchmark points?

No. I repeated OpenAI's comparison with Nano Banana Pro 2 and GPT Image 1.5.

How do I open ChatGPT Images 2.0?

On chatgpt.com I dismissed the image update popup and clicked start creating to enter image mode, on 23 April 2026.

Can ChatGPT Images 2.0 edit part of an image?

Yes. I used the selection tool to change hair color to white and to swap rabbits for elephants.
