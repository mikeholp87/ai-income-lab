Quick answer

On 21 May 2026 I rebuilt an agency site that started in Lovable. Claude Desktop wrote a Vite and React replication prompt. Codex generated the project, I previewed it locally, pushed to GitHub, and imported it on Vercel with the Vite preset. I said the first version took about ten minutes and the polished one about thirty. PageSpeed Insights showed 90 on mobile and 98 on desktop in that one lab run. I asked for a code review and did not read the results. The custom domain was left for later.

This is a Codex rebuild of my own site, not the general Codex verify-a-change tutorial. For how I split work with Claude Code, see Codex vs Claude Code. Description-footer affiliate links are not pasted here.

1. Write a Codex Vite and React prompt

I reviewed the old Lovable layout, which I called clearly vibe coded, and asked Claude Desktop for a detailed prompt that replicates the site in Vite and React. I pasted that prompt into Codex and answered questions about copy and design direction. The long prompt was not read aloud, so it is not copied here.

2. Generate and preview

Codex created components, sections, styles and a written implementation plan: sticky nav, animated hero, pricing toggle, FAQ and a consultation modal. After the first local preview I asked for extra polish such as scroll highlighting and a mobile menu.

3. GitHub, Vercel and PageSpeed

I committed, pushed to GitHub, and imported the project into Vercel with the Vite preset. Then I asked Codex for a full code review of the live build and did not read those notes on camera. PageSpeed Insights in this take showed 90 on mobile and 98 on desktop. That is one lab run, not a field study. The custom domain and DNS step were left for later. I did not measure the old Lovable site on the same test.

Done when

  • Pasted a replication prompt into Codex
  • Previewed the local Vite and React build
  • Imported the GitHub repo on Vercel

What I didn't cover

  • The results of the code review, which I requested and did not read out.
  • Connecting a custom domain.
  • A measured comparison with the old Lovable site.

FAQ

How long did the rebuild take?

About ten minutes for the first version and about thirty minutes of work in total, on 21 May 2026.

Why leave Lovable?

I found the old site clearly vibe coded and wanted a better design on my own hosting.

What were the PageSpeed scores?

90 on mobile and 98 on desktop in one PageSpeed Insights run.
