Quick answer

In Make.com create a scenario with the Facebook Messenger Watch messages trigger and a webhook with a verify token you choose, add an OpenAI create-a-completion module that writes a reply to the incoming text, and a Messenger send-a-message module that returns it. Then create an app in Meta for Developers, connect your page, generate a page access token and paste in the webhook URL. Going live needs the pages messaging permission and business verification, which was still pending in my July 2025 walkthrough, so the bot was not shown working.

This is a July 2025 build. The hardest part is the Meta developer portal, not Make.com. Replying to customers automatically can go wrong, so test with your own account and read every reply before you go live. The Make.com link is an affiliate link. For the Gmail version of the same idea, see the Make.com Gmail auto-reply.

1. Build the three-module scenario

Create a new scenario, search for Messenger and choose Watch messages. It needs a webhook, which is a listener for new messages, and a verify token that can be any text you make up. Next add OpenAI, create a completion, to write a reply to the message text, and a Messenger send-a-message module that uses the access token and the ChatGPT result as the message. A custom ChatGPT assistant module can replace the plain completion if you want one tightly scoped job: professional replies on Messenger. The Make help center shows a more complex flow with a router.

2. Create the Meta developer app

In Meta for Developers create an app, choose the Other use case and the Business type and link it to your Facebook page. Connect the page and generate the page access token. In the Messenger settings add the webhook URL from Make.com and the verify token, and subscribe to the fields you need. You can also subscribe to fields such as name and email to build a list as messages come in, but check privacy rules first.

3. Fix a failed webhook check

The first webhook verification failed. I fixed it by creating a new webhook in Make.com and pasting its URL and verify token into the app again.

4. Permissions and business verification

Before the app can go live you request the pages messaging permissions and verify your business with Meta. My approval was still pending, so I could not show a live reply. Switch the app to live only after that.

FAQ

Why did the webhook check fail?

My first attempt failed. A new webhook in Make.com with its URL and verify token pasted into the app fixed it.

Can I go live straight away?

No. The app needs the pages messaging permission and business verification first.

What is the verify token?

Any text you choose. It must match in Make.com and in the Meta app.
