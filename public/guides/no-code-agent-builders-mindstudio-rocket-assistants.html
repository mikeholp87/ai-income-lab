Quick answer

These are first impressions from August 2025. In MindStudio I never got an agent running: a launch-variable error and a publishing paywall stopped me, API access needed the business plan and I concluded Make.com was easier for my needs. In Rocket.new a prompt written in ChatGPT produced a ChatGPT-style web app in about ten minutes, with some broken controls fixed by prompts and an OpenAI key connected, though it still answered as a GPT-4 model, and a custom domain needed a 25 a month plan. The third, a custom OpenAI assistant for writing community posts called from Make.com, worked once I edited the prompt.

This guide merges three August 2025 videos. I had never used MindStudio or Rocket.new before recording, so these are learning-curve notes, not reviews of mature products. MindStudio and Rocket.new links in the descriptions were promotional, and the Make.com link is an affiliate link. For a stronger comparison of builders, see Lovable, Base44 and Replit compared.

1. MindStudio: a tour that stopped early

MindStudio is a no-code builder for AI agents with a visual editor and over 100 templates, and says the average build takes 15 minutes to an hour. Its free tier allowed 1,000 runs a month, with paid plans from about 20 a month. I started an agent with an on-demand trigger and it errored without launch variables, looked at data sources for a knowledge base and user inputs, and browsed templates, some of which need a Chrome extension. API access, which I needed to connect it to Make.com, is on the business plan. I did not get an agent running and concluded Make.com was easier for what I do.

2. Rocket.new: a ChatGPT-style app (August 2025)

Rocket.new asks what you want to build: a web app, mobile app, website, dashboard or landing page, and you do not even need an account to start. I had ChatGPT write the prompt, chose the main chat interface and a settings screen, and tokens are charged per screen. After about ten minutes I had an interface with some broken controls, and a prompt fixed the colour scheme setting. I asked it to connect OpenAI, pasted in a key, and the chat worked, though the assistant still described itself as a GPT-4 model. Publishing is easy, but a custom domain needed the 25 a month plan with 5 million tokens. I compared it with the agency site I built in Lovable in about two hours and prefer Lovable.

3. A custom OpenAI assistant from Make.com

On the OpenAI platform, the chat prompt tool wrote a detailed developer message for an assistant that writes my community posts. I pasted it into a new assistant on GPT-4, noted the option to upload files as a knowledge base with file search and tested it. The first outputs missed the format I wanted until I added reasoning and examples to the prompt. Then a one-module Make.com scenario with the Message an Assistant module returned the post text. Skool has no public API, so I paste the text by hand. I topped up API credit by a few dollars.

FAQ

Did you get a MindStudio agent working?

No. I hit launch variable errors and a paywall, so this is a learning-curve tour.

What did a custom domain cost on Rocket.new?

The 25 a month plan with 5 million tokens, as I quoted in August 2025.

How did the assistant connect to Make.com?

With the Message an Assistant module, calling an assistant created on the OpenAI platform.
