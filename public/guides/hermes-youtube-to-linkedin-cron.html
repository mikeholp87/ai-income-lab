Quick answer

Give Hermes Agent your channel URL and ID and ask for a Python script that finds your latest video and writes a LinkedIn post and a newsletter from it. The first version pulled the latest video without a YouTube API key but the writing was weak, so I moved the edits to OpenCode and the OpenAI API, fixed an unsupported max_tokens error by using max_completion_tokens, produced two post versions (reach and engagement) and a newsletter of at least 1,500 words, added dates to the file names and created a daily cron job in Hermes. I still edit and post by hand.

1. Ask Hermes for the script

In a project folder named YouTube to LinkedIn I ran Hermes and asked for a script that finds my latest YouTube video and generates a detailed LinkedIn post and a newsletter. It asked for the channel URL and channel ID, then wrote a Python file with a get-latest-video function that needed no YouTube API key.

2. Add an AI model and fix errors

The script needs a model to write the copy. I first tried a Google AI Studio key and then put an OpenAI API key in the environment file. Hermes’s drafts read poorly, so I moved the edits to OpenCode. An unsupported max_tokens error went away when I switched to max_completion_tokens.

3. Two post versions and a newsletter

The script writes version A for reach and version B for engagement, plus a newsletter. I required at least 1,500 words for the newsletter. Dates are added to the file names so each run keeps its own files and I build a running archive.

4. Schedule it

In Hermes I created a daily cron job for the YouTube-to-LinkedIn task, which is easy in the desktop app. Each day it should write new dated files for me to review. The first newsletter needed formatting fixes, and I add my video at the bottom before sending it to my 1,500 subscribers.

FAQ

Does it post to LinkedIn for me?

No. It writes files, and I copy them into LinkedIn myself.

Why switch to OpenCode?

Hermes’s first drafts read poorly, so I made the edits in OpenCode with the OpenAI API.

What was the max_tokens error?

The model rejected max_tokens. Using max_completion_tokens fixed it.
