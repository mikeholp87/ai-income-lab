Quick answer

On 28 April 2026 I opened a TubeAnalytics design system in Claude Design, imported a design.md that Claude Code had already written, hit a private-GitHub block, then connected the GitHub app and rebuilt marketing and dashboard kits from source. The Code Web handoff tried to create a new app, so I used the fetch-this-design-file command in the terminal instead. Weekly usage hit 100 percent. I topped up about $5, switched to Haiku at $1 per million tokens versus $3 for Sonnet, and Haiku said nothing more was needed. The localhost site still looked the same until Codex 5.4 updated CSS. TubeAnalytics is my own product.

This is a Claude Design website redesign, from design system to Claude Code handoff. TubeAnalytics is my own SaaS. Captions that say Two Ben Analytics mean TubeAnalytics. This is the redesign pass. The first Claude Design test is How to Use Claude Design: First Pitch Deck Tutorial. A Codex rebuild of a different site is Rebuild a Site in Codex. design.md was prepared in Claude Code before this video and is not pasted here.

1. Load a Claude Design design system

I opened Claude Design and an existing TubeAnalytics design system. Brand guidelines plus an imported design.md covered fonts, color palette, layout, border radius, animations, background, nav, and visual contexts for dark and light. Create a new design system offered GitHub, fonts, logos, and a dropped design.md. First pass failed because the repo was not accessible via the GitHub app while it was private. I continued from design.md only and registered preview cards for navigation, hero, features, pricing, and footer. It built a marketing UI kit as index.html, a dashboard UI kit, a type scale, colors, chart colors, and buttons.

2. Connect GitHub and rebuild from source

I authenticated GitHub with Claude Design Import access to all repos, then rebuilt the marketing and dashboard kits from real source and rebuilt the hero. The design files tab listed HTML, source, components, UI kits, design.md, a generated skill.md, and a readme. I approved logo, animations, card patterns, badges, nav, marketing UI, dashboard light and dark, fonts, accent colors, and buttons. Extra screens included videos, analytics, and audience. I also asked:

create screens for performance, calendar, engagement.

3. Hand off from Claude Design to Claude Code

Handoff options were a CLI command, a zip, and Claude Code Web. The web option prompt was "I exported this design from Claude Design. Read readme.md in this workspace, then and implement the designs as described there." That created a new app, which I closed. The command I wanted was:

Fetch this design file, read its readme, and implement the relevant aspects of the design.

I ran that in the terminal and mentioned the front-end design skill. Weekly usage went from about 70 to 84 percent, then 100 percent, then 87 percent after extra usage. I topped up about $5 and switched to Haiku, which I said was $1 per million tokens versus $3 for Sonnet. Haiku reported the design already matched and no further implementation was needed. The dev server still looked the same.

4. Finish visible CSS in Codex

I gave the design system to ChatGPT Codex 5.4. Codex updated CSS for buttons, badges, cards, typography, textareas, and selects, then I pushed and deployed. The marketing site showed new typography and buttons. The dashboard, which was not public, showed a new shell, time range, header, and sidebar. Dark and light still worked. I said it did not look all that much different and still needed more work. ChatGPT 5.5 had just come out that week and was not used for this pass.

Done when

  • Imported design.md into Claude Design
  • Connected GitHub if the repo was private on the first try
  • Handed the kit to Claude Code or Codex and compared the live CSS

What I didn't cover

  • The contents of design.md. It was written before this video.
  • A large visual redesign. Haiku made no visible change. Codex changed CSS. I still wanted more work.
  • Credit prices after 28 April 2026. The $1 versus $3 Haiku and Sonnet figures are from that day.

FAQ

Whose site did you redesign?

TubeAnalytics, which I own. Captions that say Two Ben Analytics are wrong.

Why did the first GitHub import fail?

The repo was private, so Claude Design could not read it until I granted the GitHub app access.

Did Claude Code change the look?

Not in this pass. Haiku said the kit already matched. Codex 5.4 updated the CSS.

Is this the first Claude Design video?

No. The 22 April pitch-deck test is a separate getting-started guide.

Can Claude Design hand off to Claude Code?

Yes. Handoff options were a CLI command, a zip, and Claude Code Web. I used the fetch-this-design-file command in the terminal.

How did Claude Design and Claude Code split the work?

Claude Design built the design system and UI kits. Claude Code and Codex worked in the repo. Codex 5.4 made the visible CSS change.
