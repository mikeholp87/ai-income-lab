Choose your first AI automation project.

You don’t need to learn every AI tool at once. Pick a path based on the work you want to do, finish a small example, then add complexity.

  • Automate a repeated business task

    Start with the Beginner’s Automation Course in AI Income Lab. It covers simple business automations in Make.com. Access unlocks at Skool level 2, or immediately with Premium or VIP. The classroom also includes How-To Guides and Make.com Automation Templates.

    Begin with a task you can check yourself, such as moving a test record between two tools. Keep customer data and automatic sending out of your first experiment.

    Find the beginner course in the classroom

  • Build with a coding assistant

    The classroom has Claude Code & Skills and Codex Tutorials & Courses. Choose the assistant you already use, then ask it to explain one small project before changing it.

    For a concrete project, use the video-feed guide below. You can inspect its source, run its tests, and compare the result with this website.

    Explore the coding courses

    Free first watch: How I Built An AI Video Editor Inside Claude Code

  • Create an avatar video or voice agent

    The Complete AI Avatar Video Course is included with Premium and VIP and covers HeyGen, ElevenLabs, and Make.com. The VAPI AI Voice Agent Course covers building a voice agent with VAPI and ElevenLabs. It unlocks at Skool level 4, or immediately with Premium or VIP.

    Use your own voice and likeness or material you have permission to use. Check the tools’ current usage costs before starting.
