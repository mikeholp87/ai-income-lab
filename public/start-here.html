Choose your first AI automation project.

You don’t need to learn every AI tool at once. Pick a path based on the work you want to do, finish a small example, then add complexity.

Free written build guides

  • Make and verify a code change with Codex: add a failure check to a local example and review the diff.
  • Build your first Make.com automation: route approved sample requests between spreadsheet tabs.
  • Make your first API request: run a local example and understand keys, model IDs, and request failures.
  • Build a YouTube feed in React: work with live data, preserve a saved fallback, and render useful HTML.
  • Track clicks only after consent: distinguish a click from a conversion and verify that optional trackers stay off.

The guides and videos below are free to read or watch without a Skool login. The tools used in a project may require an account or incur usage charges.

  • Connect an AI API through a gateway

    Bring: a terminal, an API provider account, and a test key. Finish: send one request, inspect the response, and check which provider handled it.

    Free first build: make your first API request. Pair it with 9Router setup and request checks, which includes written prerequisites and verification steps.

    Continue with connecting providers and checking limits and cost tracking and fallbacks. Verify current provider terms and costs before routing a real workload.

  • Build a useful creator website

    Bring: Node.js, a code editor, and a small local project. Finish: show a video feed that still works when its data source is unavailable.

    Free first build: build a YouTube feed in React. New to coding assistants? Start with the beginner Claude Code walkthrough. On Linux, use the Codex installation and compatibility notes.

    Practice the Codex small-change workflow, or follow the OpenCode desktop habit-tracker build and provider-selection walkthrough. Then audit internal links with Codex and check consent before tracking clicks.

    Member next step: find Claude Code & Skills and Codex Tutorials & Courses in the classroom; check the current plans for course access.

  • Automate a repeated business task

    Bring: a Make.com or n8n account and sample records you can inspect. Finish: move a test record between two tools and verify the output before enabling automatic sending.

    Free first build: route sample requests with Make.com. Pair it with Make.com AI Automations Without Code (full one-hour course). For a different workflow, explore the LinkedIn automation build with n8n.

    Member next step: the Beginner’s Automation Course covers Make.com business automations. It unlocks at Skool level 2 on Standard, or immediately with Premium or VIP. Find it with the How-To Guides and Make.com Automation Templates in the classroom. The 6,400+ n8n template library is included with VIP.

  • Create an avatar video or voice agent

    Bring: your own voice and likeness, or material you have permission to use, and an account for the tool you choose. Finish: review one short avatar clip or test a voice-agent conversation before sharing it.

    Free first watch: HeyGen AI Avatar Tutorial or How I Built an AI Phone Agent That Actually Works (VAPI). Check the tools’ current usage costs before starting.

    For a longer example, the HeyGen course and automation notes explain the API failures encountered in the recording.

    Member next step: the Complete AI Avatar Video Course covers HeyGen, ElevenLabs, and Make.com and is included with Premium and VIP. The VAPI AI Voice Agent Course covers VAPI and ElevenLabs; it unlocks at Skool level 4 on Standard, or immediately with Premium or VIP. Explore both in the classroom.
