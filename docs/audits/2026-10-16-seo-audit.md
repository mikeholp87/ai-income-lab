# SEO audit: October 16, 2026

Site: https://www.ai-automation-station.com/

## Summary

No crawl, indexing-directive, metadata, or structured-data blocker showed up in the public audit. All 243 URLs in the page and video sitemaps were reachable, indexable, self-canonical, and linked from the site. Titles and descriptions were unique, each checked page had one H1, and the JSON-LD parsed. Robots.txt, both sitemaps, `llms.txt`, and sampled search and AI crawler requests returned successfully. Sampled invalid URLs returned 404 and alternate host/protocol URLs redirected to the canonical site.

The automated rule score was 100/A, but this was a partial audit rather than a complete SEO health score: the Jev service rejected its configured key, and Google's PageSpeed Insights endpoints returned HTTP 429. The auditor's own completeness report marks content quality and field performance unavailable. Search Console indexing, rankings, and traffic were not checked.

## Fixes made

- Updated the homepage `<lastmod>` in `public/sitemap.xml` to October 16, reflecting the recent substantive hero, pricing, FAQ, and course changes. Unchanged page dates remain untouched.
- Added a 640-pixel WebP source and responsive `srcset`/`sizes` for the Runable course image. The file is 28 KB versus 82 KB for the original, a 53 KB reduction when the smaller image is selected. The original remains available for larger displays.

These are watch pages: each has the video title, description, player, upload metadata, `VideoObject` markup, and surrounding discovery links. The word-count threshold is a heuristic; it did not identify a broken or empty page. Adding filler copy would not address a verified issue, so no bulk content changes were made.
