Full audit run after commit `6a5a35b` (desktop hero rebalance). Nine specialist passes ran in parallel (technical, content, schema, sitemap, performance, visual, AI search, search experience, backlinks); every finding below that drives a recommendation was re-checked against the live site or the repo before inclusion.

Why this is lower than the earlier 92–93: that audit crawled 18 pages. This one weighs all 213 watch pages added in `37b30a5`, and those pages are where nearly every content and on-page deduction comes from. The core site did not get worse.

## The one constraint that matters most

The watch pages are thin, unlinked from the homepage, and listed in a sitemap Google reported it couldn't fetch. Three separate passes (content, AI search, search experience) reached the thin-page conclusion independently. A site that is 90% thin pages risks the helpful-content signal pulling down the good pages too, and the watch pages are the only page type that can win topic queries (the search-experience pass found written video companions ranking for this site's own topics, e.g. a ~1,500-word "Dots vs GrokBot" write-up outranking a 123-word watch page for a video with ~30x the channel's usual views).

## Action plan

Ordered by what unblocks the most. Items in the same tier can run in parallel.

### Tier 1: one data change that closes four findings (code, ~1 hour)

**1. Fetch duration and views, keep the description body.**
- Evidence: `api/videos.js` asks `videos?part=status` only; `summarize()` (`src/youtube.js:21`) keeps only the first link-free paragraph, so chapter timestamps (present on YouTube, e.g. 8+ on `Ip8KBwDixJs`) are dropped.
- Fix: request `part=status,contentDetails,statistics` (still 1 quota unit per 50 videos). In `parseUploads`/`renderWatch` (`src/archive.js`): emit `duration` and `interactionStatistic` in VideoObject, `video:duration` in the video sitemap, show the duration and an "In this video" chapter list linking to `youtube.com/watch?v=ID&t=Ns`, and add `hasPart` Clip entries. `src/youtube.js` already formats durations for the homepage, so reuse it.
- Unblocks: items 5 and 6, and Google's key-moments eligibility.
- How we'd know it failed: Rich Results Test on a watch page still shows duration missing, or the GSC Video pages report flags "missing duration".

### Tier 2: quick independent fixes (code, under 1 hour total)

**2. Make the video sitemap, archive and watch pages survive a YouTube API failure.**
- Evidence: `api/videos.js` returns `503 no-store` for the sitemap, archive and every watch page when an instance starts cold and the YouTube call fails. This is the most plausible cause of the 2026-10-08 "Couldn't fetch" in Search Console (file content, type, size and encoding all check out).
- Fix: generate a full uploads snapshot in `scripts/refresh-videos.js` at build time and use it as the fallback instead of a 503.
- Then: resubmit `/video-sitemap.xml` in Search Console.
- Failure check: GSC sitemap status still "Couldn't fetch" a week after resubmission.

**3. Cache hashed assets for a year.**
- Evidence (live): `/assets/main-*.js` returns `cache-control: public, max-age=0, must-revalidate`.
- Fix: in `vercel.json` add a header for `/assets/(.*)` with `public, max-age=31536000, immutable`.
- Failure check: `curl -sI` on an asset still shows `max-age=0`.

**4. Fix contradictory billing copy.**
- Evidence: `public/llms.txt:10` says "billed monthly"; `public/terms.html` says "billed monthly at the price shown during checkout"; the homepage FAQ (`src/main.jsx:134`) offers annual billing at $290/$490/$890. The terms page also never names who runs the site.
- Fix: align terms and llms.txt with the FAQ; name the operator in the terms.

### Tier 3: internal links (code, ~1–2 hours; better after Tier 1)

**5. Link to watch pages from the site itself.**
- Evidence: `watchUrl` (`src/main.jsx:144`) sends every homepage video link to youtube.com, so the strongest page passes nothing to `/watch/`. Watch pages link to no other watch pages. `/guides/first-api-request.html` links its 9Router video to YouTube although `/watch/geKngm3sg3w` exists. `/start-here.html` has no watch links.
- Fix: point embeddable video cards and the featured title at `/watch/<id>` (keep YouTube for non-embeddable videos, which 404 on `/watch`). On each watch page add 3–5 related builds matched on title keywords, plus the matching guide.
- Trade-off: visitors stay on-site and see the Skool offer; embedded plays still count as YouTube views. The `Video Played`/`CTA Clicked` events will shift from `watch_video` (outbound) to on-site plays, so compare funnels by week, not across the change.
- Failure check: GSC Links report shows no growth in internal links to `/watch/` after recrawl.

### Tier 4: entity cleanup (code ~30 min + your profile edits)

**6. Make "AI Automation Station" and Mike Holp one connected entity.**
- Evidence: WebSite schema `name` is "Mike Holp" (`index.html`), watch titles end "| AI Automation Station", terms title says "AI Income Lab". Watch-page VideoObject `author` is an inline Person without the homepage's `@id`. Brand searches return no result for the domain.
- Code fix: WebSite `name` "AI Automation Station" with `alternateName` "Mike Holp"; add an Organization node (`founder` → `#mike`, `sameAs` YouTube and Skool); VideoObject `author`/`publisher` → `{"@id": ".../#mike"}`; BreadcrumbList on watch pages; CollectionPage/ItemList on `/videos`; Article on the three guides; mention the brand in the homepage meta description.
- Your fixes (off-site, the sites' own settings): GitHub profile Website field currently points to tubeanalytics.net, so change it to this site; add the site to the Skool group description, X and LinkedIn bios, and the README of each public repo.

### Tier 5: the content work that moves rankings (writing, needs you)

**7. Written companions for the top watch pages.**
- Start with `vauqktcB6ak` (Dots vs GrokBot) and `Ip8KBwDixJs` (GrokBot chief of staff), then the next highest-viewed videos.
- Each one: what you tested, a short results table (access, price, setup time, what broke, verdict), who should pick which. Render as an optional per-video notes block in `renderWatch`; pages without notes are unchanged.
- This must be your first-hand verdict. It can be drafted from the transcript, but the "what broke" and verdict lines have to come from you to count as experience.
- Failure check: those pages still absent from GSC queries for their topic after 4–6 weeks.

**8. Match more videos to a real course offer.** 161 of 213 watch pages fall through to the generic "Put what you watched into practice" offer in `src/video-offer.js`, including GrokBot, Dots and plain Claude videos. Add rules only where a real course exists.

**9. Tidy watch-page metadata (after 1 and 7).** 157 of 213 meta descriptions exceed 160 characters; cut at a sentence near 155. 127 of 213 descriptions open with "In this video", "Discover" or "Learn how". Typo on `/watch/1aG1XbAQj-k`: "Clade Opus 5".

### Lower priority

- **Consent bar covers the hero card's Skool link on 1366×768 until dismissed.** Add bottom padding to `body` while the banner shows. The 2026-10-08 hero fit the card to exactly 768px, which made this visible.
- **Trailing-slash URLs 404** (`/videos/`, `/watch/<id>/`). Add `"trailingSlash": false` to `vercel.json`. Don't enable `cleanUrls`: it would change the `.html` canonicals already in the sitemap.
- **Sitemap hygiene:** add `lastmod` to the 15 URLs without it; drop `changefreq`/`priority` (Google ignores them). Add `first-api-request.html` to `llms.txt`.
- **Small tap targets** under 44px: header icons on phones (40px), footer links, "Privacy details", watch-page action links (23px tall).
- **IndexNow** (helps Bing/Copilot only): optional key file plus a ping from `scripts/refresh-videos.js`.

## Deliberately not recommended

- **Click-to-load facade for the watch-page player.** It would cut ~1 MB per page, but Google indexes video more reliably when the player iframe is on the page, and the `37b30a5` release was built around that.
- **Noindexing the thinnest watch pages now.** The video sitemap was submitted today. Run item 1 first (it adds chapters and the full description automatically), re-measure, and only then consider noindex for pages still under ~30 unique words.
- **Rewording the slogan H2s as questions.** It would help passage matching slightly but undoes the chosen visual direction.
- **FAQPage schema.** Google retired FAQ rich results for all sites on May 7, 2026; the homepage correctly has none.
