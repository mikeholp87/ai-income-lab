## What the live results show

- **Every topic has YouTube videos on page 1**, so the channel's videos can rank alongside (or instead of) the guides.
- **"codex vs claude code"**: page 1 is dated 2026 comparisons with benchmarks, pricing and a verdict (towardsai, duet.so, langwatch, mindstudio, softr). Our guide's angle, how one person routes tasks between both, isn't on page 1; it is closest to "When to use Codex vs Claude Code (and why to run both)" at #24.
- **"hermes desktop app"**: page 1 mixes Julian Goldie, an X article, Reddit, a 480-view YouTube video and unofficial docs sites. A Medium post notes there are two apps named Hermes Desktop. Checking that led to a fix: Nous Research now ships an official Hermes Desktop for macOS 12+ and Windows 10/11 (no Linux build), released after the video. The guide now points Mac and Windows readers to it and keeps Hermes One for Linux.
- **"n8n self hosted"**: page 1 is hosting providers (Sliplane, xCloud), Docker guides and YouTube. Nearly every result is about Docker or a VPS, which matches the guide's note that npm installs are deprecated from n8n 3.0.
- **"dataforseo mcp"**: DataForSEO's own pages hold six of the top ten, plus a YouTube setup video and Reddit. Hard to outrank; the guide's value is the Claude Code walkthrough with a checkable first query.

## Recommendations

1. **Claude Code vs Codex** is the biggest opportunity: about 20,000 searches a month across both word orders at difficulty 6–22. Put "Codex vs Claude Code" in the title, add a short dated "which to pick" summary near the top, and say which plans and models it was tested on. Keep the honest "not a benchmark" framing; page 1 is full of benchmark claims.
2. **Hermes desktop app** (difficulty 4) is the easiest win: the guide now covers both apps, so add "Hermes Desktop" to its title and description.
3. **Self-host n8n**: add a short Docker section, since searchers and page 1 lean that way.
4. Don't spend more on Make.com, API request or consent keywords; search demand is too low. Those guides serve readers coming from the videos.
5. Recheck positions in Search Console in two to three weeks rather than paying for repeat SERP pulls.
